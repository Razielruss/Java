# Projekt: Modellklasse 2

## Informationen zum Projekt
In diesem Tutorial wird erklärt, was eine `ArrayList` ist und welche Funktionen sie hat. Dabei wird anhand eines  
Beispiels aus der Praxis `Methoden` und `Modellklassen` erstellt und eine `Beziehung` zueinander hergestellt.  
Dabei werden paar `Funktionen` aus dem Beispiel nachprogrammiert und am Ende Übungsaufgaben gegeben,  
damit du besser in Java wirst.

## Java Projekt importieren
**1. Projekt Suche öffnen**  
   Klicke oben im Menü auf 
   `File->Open Projects from File System...` 

**2. Verzeichnis wählen**   
   Im geöffneten Fenster auf  `Directory...` klicken und das Projektverzeichnis 
   auswählen, das den `src` Ordner enthält. 
   

**3. Projekt importieren**   
  Klicke auf Finish und das Projekt sollte direkt ausführbar sein
